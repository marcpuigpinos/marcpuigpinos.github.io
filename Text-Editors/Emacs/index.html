Emacs

Install Emacs:

  • Debian/Ubuntu
sudo apt-get install emacs
  • Fedora
sudo dnf install emacs
  • Arch
sudo pacman -S emacs

Configure emacs​

A basic Emacs configuration starts by editing the init.el file foun in the ~/.emacs.d/ directory. An example of a simple Emacs configuration can be found here. Just copy the init.el and the emacs.custom.el file to ~/.emacs.d folder.

Note: To build vterm it is necessary to have installed C/C++ compilers, make and Cmake. It is also possible to use the configuration without vterm by commenting the line at respect in the init.el config file.

Copilot​

If my configuration is used and the copilot section is not commentted, then it is necessary to install the following. (Requirements: to have installed npm)

To use Copilot, do the following (requirement: install npm):

Download the Emacs plugin:

git clone https://github.com/copilot-emacs/copilot.el ~/.emacs.d/copilot

Download and install copilot cli.

npm -g --prefix ~/.emacs.d/.cache/copilot install @github/copilot-language-server

Open emacs and run:

M-x copilot-install-server
M-x copilot-login

Language Server Protocol (LSP)​

To use LSP within Emacs is necessary to install the LSP servers for C/C++, Python and Fortran.

C/C++​

Install clangd.

  • Debian/Ubuntu:
sudo apt-get install clangd
  • Fedora:
sudo dnf install clang-tools-extra
  • Arch:
sudo pacman -S clang

Python​

Install pyright using pip:

pip install pyright

To install pyright system wide in some Linux distributions, it is necessary to run the following command:

pip install pyright --break-system-packages

Fortran​

Install fortls using pip:

pip install fortls

Similar to pyright, in some systems it asks to break system packages.

pip install fortls --break-system-packages
