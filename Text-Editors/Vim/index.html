Vim

Overview​

Vim is a highly configurable text editor designed for efficient editing of plain‑text files. It runs in the terminal and provides powerful keyboard‑based navigation, extensibility through plugins, and support for many programming languages.

Installation​

The installation steps differ slightly between distributions. The commands below install the binary with clipboard support when available.

Fedora​

For a compiled build that supports the system clipboard, install vim-X11 (works on both X11 and Wayland):

sudo dnf install vim-X11

Note: The binary with clipboard support is named vimx. To check the clipboard support open vimx and run :echo has('clipboard'). It must return 1.

Dependencies for Plugin Manager and LSP Support​

Vim‑plug is a lightweight plugin manager, while coc.nvim provides language‑server integration. Install the required tools with:

Fedora​

sudo dnf install git nodejs npm

Installing vim‑plug​

Download the plug script into Vim’s autoload directory:

curl -fLo ~/.vim/autoload/plug.vim --create-dirs \
  https://raw.githubusercontent.com/junegunn/vim-plug/master/plug.vim

Open Vim and run :PlugInstall to fetch the plugins listed in your .vimrc.

Tip: If you plan to use language‑server support, install the desired servers (e.g. clangd, pyright, rust-analyzer, fortls).

Configuration – .vimrc​

Below is a minimal but functional configuration that covers UI settings, plugin management, LSP integration, and appearance.

" ==============================================================
" 1 General Settings
" ==============================================================

" Line numbers & status line
set number              " Show absolute line numbers
set relativenumber       " Show relative line numbers for navigation
set ruler                " Display cursor position in the status line
set laststatus=2         " Always show status line
set statusline=%l,%c%V   " Custom format: line, column, percentage

" Text display
set wrap                 " Wrap long lines at the screen width
set showmatch            " Highlight matching parentheses/brackets
syntax on                " Enable syntax highlighting
set mouse=a              " Allow mouse usage in all modes

" Search behaviour
set incsearch            " Incremental search feedback
set ignorecase           " Case‑insensitive by default
set smartcase            " Override when a capital letter is used
set hlsearch             " Highlight all matches

" Indentation & tabs
set tabstop=4             " Number of spaces per Tab character
set shiftwidth=4          " Indent width for >> and <<
set expandtab             " Convert Tabs to spaces
set autoindent            " Copy indent from the previous line
set smartindent           " Intelligent indentation for code

" File & system integration
filetype plugin indent on   " Detect file types and load appropriate settings
set clipboard=unnamedplus  " Use the system clipboard

" Undo history – persistent across sessions
if !isdirectory(expand('~/.vim/undo'))
    call mkdir(expand('~/.vim/undo'), 'p')
endif
set undofile            " Store undo history on disk
set undodir=~/.vim/undo
set undolevels=1000      " Keep many undo levels

" ==============================================================
" 2 Plugin Management – vim‑plug
" ==============================================================
call plug#begin('~/.vim/plugged')

" Language‑server and autocompletion
Plug 'neoclide/coc.nvim', {'branch': 'release'}
Plug 'honza/vim-snippets'

call plug#end()

" ==============================================================
" 3 Plugin Configuration – coc.nvim (LSP)
" ==============================================================

" Completion menu navigation with Tab/S-Tab
inoremap <silent><expr> <Tab>  coc#pum#visible() ? coc#pum#next(1) : "\<Tab>"
inoremap <silent><expr> <S-Tab> coc#pum#visible() ? coc#pum#prev(1) : "\<S-Tab>"

" Confirm selection with Enter
inoremap <silent><expr> <CR>  coc#pum#visible() ? coc#pum#confirm() : "\<CR>"

" Install language servers automatically (coc‑fortran removed due to 404)
let g:coc_global_extensions = ['coc-clangd', 'coc-pyright', 'coc-rust-analyzer']

" ==============================================================
" 4 Appearance
" ==============================================================
colorscheme desert
